# Ventar Slavich — черновик рестайлинга

Статический сайт (чистые HTML/CSS/JS, без сборки). Черновик для показа заказчику — переиспользованы реальные тексты и структура с текущего сайта ventar-slavich.photos, дизайн полностью новый.

## Идея дизайна

Бренд объединяет два направления, поэтому дизайн-система работает в двух настроениях:

- **Consalting EU** — строгий, деловой тон: графит + приглушённое золото, спокойная типографика (`.mode-consulting`, секции `.section--consulting-bg`).
- **Курс «Монтаж Reels & Shorts»** — динамичный, креаторский тон: чёрный фон + электрический градиент розовый→оранжевый→бирюзовый (`.mode-creator`).
- Главная страница показывает оба направления рядом (блок «Выберите, что нужно вашему бизнесу»), чтобы сразу было видно позиционирование.

Жёлтый баннер вверху каждой страницы — пометка, что это черновик; тексты, телефоны и ссылки взяты с текущего сайта и требуют проверки с заказчиком перед публикацией.

## Структура

```
index.html            — главная (оба направления + блог + контакты)
consalting-eu.html    — маркетинг-консалтинг
videomontazh.html     — курс по видеомонтажу
contacts.html         — контакты
css/style.css         — вся дизайн-система
js/main.js            — мобильное меню
```

## Как посмотреть локально

Просто открыть `index.html` в браузере — внешних зависимостей нет (шрифты подключены через Google Fonts CDN).

Либо поднять локальный сервер:
```bash
cd ventar-restyle
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как задеплоить

### Вариант 1 — Netlify Drop (без гита, самый быстрый)
1. Зайти на https://app.netlify.com/drop
2. Перетащить папку `ventar-restyle` целиком в браузер
3. Получить ссылку вида `random-name-123.netlify.app` — можно сразу отправлять заказчику

### Вариант 2 — GitHub + Netlify (для дальнейшей работы с версиями)
```bash
cd ventar-restyle
git init
git add .
git commit -m "Draft restyle"
# создать репозиторий на GitHub, затем:
git remote add origin <URL репозитория>
git push -u origin main
```
Дальше на netlify.com → "Add new site" → "Import from Git" → выбрать репозиторий → Deploy.

### Вариант 3 — GitHub Pages
В настройках репозитория Settings → Pages → Source: `main` / `/ (root)`.

## Что нужно уточнить с заказчиком перед публикацией

- Актуальные телефоны/контакты (сейчас скопированы с текущего сайта)
- Ссылка на форму записи на мастер-класс (сейчас `forms.gle` с текущего сайта)
- Реальные фото/видео вместо плейсхолдеров (превью блога, фото преподавателя)
- Нужен ли переключатель языка (EN/DE) — сейчас только русский
